## Milestone 1: model, translator, differential tests (done)
Core changes (all RISC-V-only; x86/ARM untouched):
* `Asm/Riscv.lean`: new instructions `lbu`, `sb`, `vsetvlie8 d a lmul` (`vsetvli d, a, e8, m<lmul>`: `vl` in
  bytes; fails if `avl > 8·vlmax·lmul`, so no vl choice is involved), `vle8`, `vse8` (word `j` of the
  transfer ↔ register `d + j / vlmax`, lane `j % vlmax`; `vl % 8 = 0` required).  Byte addresses are
  region-relative: byte `o % 8` of word `o / 8` (`wordOf`, `byteOf`); `lbu` = shift+mask of the word,
  `sb` = masked insert (`insByte`, read-modify-write of the word); `vle8`/`vse8` at a misaligned address
  assemble each word from / split it into the two words it straddles (`joinWords`, `splitWords`,
  `loadBytes`, `storeBytes`, `setGroup`, `groupWord`, `setLanes`).  All built from `LaneOps`, so the
  homomorphism / relocation / footprint proofs are structural.
* **M9 fixed**: `vsh .sll/.srl a n = shl/shr a (n % 64)` (hardware: low 6 bits).
* `RiscvHom` (`exec_map`, `err_exec`), `RiscvReloc` (`decodes` += base of the byte accesses, `exec_reloc`;
  `wordOf_reloc`, `byteOf_reloc`: relocations move by multiples of 8 bytes), `RiscvFoot` (`writes`:
  `sb` its word, `vse8` its `vl/8` (+1 if misaligned) words; `exec_frame`), `RiscvEntryCtl` (`isVec` +=
  `vle8/vse8` (read `vl`), `ctlAfter vsetvlie8` = `vl` defined; `exec_ovr`, `exec_pc`),
  `RiscvSteps` (`usesVlmax` += the three byte-vector instructions; new `Instr.isVset` = only the e64
  `vsetvli`, where the hardware may choose `vl`), `RiscvChoice` (`execCh_map`/`execCh_min` by `isVset`;
  new `vlFor_not_isVset`, `execCh_not_isVset`; old statements unchanged).
* `Kernels/RvVl.lean`: the scalar kernels' `vl`-dirty intervals are now the whole program
  (`[(1, 5430)]`, `[(1, 3499)]`): the byte loops fall through instead of stopping at `unsupported`.
* Translator `asm2lean.py`: `lbu`, `sb`, `vsetvli …, e8, m1/2/4/8`, `vle8.v`, `vse8.v` (unmasked);
  `vsetvli` with `rs1 = x0` is `unsupported` (VLMAX / keep-vl semantics, not modelled; unused);
  new guard `check_vtype` (forward may-analysis of the last `vsetvli`: no e64 vector instruction under
  an e8 setting, `vle8/vse8` only under one) — the model has no `vtype`.  The 4 `Program.lean`
  regenerated: only the 14 former `unsupported` lines change.
* `Tools`: `riscvStoreCells` += `sb`, `vse8`; `riscvMisalign` and `KT_MIS=mi,mo` (kttool runs with the
  buffers at byte offsets `mi`/`mo`, the message shifted accordingly).
* `gen_plan_proof.py`: `INV0`/`INVK` (the invariant locations at a segment's ends: `input` (default) /
  `out` (default) / `regs` / `mem<r>` / `all`; round-constant look-alikes dropped there).

Differential tests (`difftest/rvgen.py`: templates for `lbu`/`sb` at any byte offset, e8 `vle8`/`vse8`
at every LMUL and vl, load+store pairs between misaligned buffers, the two kernel bounce sequences;
shift counts ≥ 64 for `vsll/vsrl/vror.vx`), qemu-riscv64 `rv64,v,zbb,zvkb` VLEN 128/256/512, two seeds:
0 mismatching forms (dt1: 5386/5376/5375 states compared, dt2: 5377/5381/5386; ~130 `lbu`, ~130 `sb`,
~470 `vle8`, ~470 `vse8`, ~110 per bounce sequence per VLEN, 59 shifts by counts ≥ 64 at VLEN 128).

## Milestones 2–3: rv64_x1 and zbb_x1 at any alignment
Proof structure (per node; `Kernels/<Ns>/AllUIn.lean`, `AllU.lean`, `All.lean`):
* **Segments** (symbolic, generated by `gen_segments_rvu.sh <k> <Ns> <core_end> <sx_a> <sx_b>`; rv64:
  `5377 5391 5405`, zbb: `3446 3460 3474`): `GenSE` frame stores (control: sp only; a0/a1/a2 spills as
  *moves*), `GenSI` [23,31) the 8 loads from the input node (aligned path), `GenSJ` [410,418) the 8 loads
  from the bounce buffer (run with `KT_MIS=1,0`), `GenSC` [31, core_end) constant lanes + 24 rounds
  (registers → registers; writes only the 4 spill words), `GenSX` restores.  No segment has a pointer
  spill or the count as a control word (`FORBID_CTL`), so none depends on the misalignment or count.
  `gen_plan_proof.py` got `INV0`/`INVK` for the invariant locations at segment ends.
* **Concrete steps** (`Kernels/RiscvBytes.lean`, kernel-independent): `St T p R M` (control part `Ctl0`,
  pc, registers, memory) with one lemma per instruction form (`St.ld/sd/addi/andi7/mv/li/brz/j`);
  the byte-copy loop `copy_loop` for any count, regions and byte offsets (induction, `CopyAt`; bytes via
  `byteAt`/`storeByte`, bit-vector facts by `bv_decide` per byte position); `wordAt`, `nodeWordsB`,
  `DigestB` (byte-addressed digest; `digestB_zero`: at offsets 0 it is `LibX86.Digest`).
* `AllUIn.in_part` (head test, copy-in if `mi ≠ 0`, the loads), `AllU.core_part`, `AllU.out_part` (stores
  directly or into the buffer + copy-out if `mo ≠ 0`), `iter` (+ back edge), `loop`, `epilogue`,
  **`rv64_x1_allU` / `zbb_x1_allU`**: for all `mi mo < 8`, `off`, `c` with `64(off+c) ≤ 2^54`:
  `32 + c·iterSteps mi mo` steps (`iterSteps = (13 | 400) + core + (10 | 203) + 5`; rv64 aligned 5374,
  zbb 3443) halt, no fault, no tail call, output bytes before `mo + 32·off` kept, `DigestB` for every node.
* `All.lean` (library interface, unchanged statements): `rv64_x1_all`/`zbb_x1_all`, `norm_thm`, `kernel`,
  `kernel_ch` now derived from the `mi = mo = 0` case (the old `GenSB` body is gone).
* Library layer (new, additive): `Kernels/LibRvU.lean` (`EntryRU`, `EntryRvU mi mo`, `NormThmRvU(Ch)`,
  `mkKernelRvU(Ch)`, `libOk_of_stop`, `lib_noTail`, `lib_rvU(_ch)`, `words_of_bytes`),
  `AllU.kernelU(_ch)`, `Kernels/RvLibU.lean` (`tableU`, `libU`, `libU_ch`: the two scalar kernels at any
  `mi, mo`, any `vlmax`, any vl choice).
* zbb files are generated from the rv64 ones: `gen_all_rvu.py zbb_x1 ZbbX1 -1931`.

Pitfalls met: `rw [lemma _ _ (Or.inr (by decide))]` elaborates the `by decide` before unification
(metavariables) — give the side condition's type (`show … by decide`) or explicit arguments; `omega` does
not see through `(⟨r, o⟩ : Addr).off` — `show` the unfolded form first; `generalize … at h` only abstracts
syntactic (up to instances) occurrences, `↑off + ↑k` is not `↑(off + k)`; `simp [upd]` may close a goal
completely (then a following `exact` fails).  Debugging before a long segment build: a stub module with
the generated `Seg` statements as axioms (remote-only scratch files `GenSCStub.lean`, `AllUT.lean`;
never committed) let `AllU`/`All` be checked hours before the real `GenSC` was built.

## RVV at misaligned buffers: plan (not done)
The model, translator and difftests cover the RVV bounce instructions (`vsetvlie8`, `vle8`, `vse8`,
misaligned and aligned, VLEN 128/256/512).  The proof plan, reusing the scalar method:
* misaligned iff `a7 = (a0|a1) & 7 ≠ 0` (then *both* buffers go through the stack); `a7` is constant over
  the call.  The head takes `9..11` (`li t4, 8; bleu t3, t4; mv t3, t4`): `vl = min(r, 8, VLMAX)` =
  `min(r, VLMAX)` for VLEN ≤ 512 — but under a vl *choice* `ch` the request is `min(r, 8)`, so the
  batch counts differ from the aligned `nb ch`; deterministic `min` first.
* restructure each body variant `GenB<w>` into `IN_al<w>` [14,22) (`vlseg (a1)`), a shared core
  `CORE<w>` [22,368) (a0/a1/a7 as *moves*, not control words), `OUT_al<w>` [368,380); misaligned:
  `IN_mis<w>` [21,22) (`vlseg (sp)`, `KT_MIS` run), `OUT_mis<w>` [371,372) (`vsseg4 (sp)`); the bounce
  copies `16..20` and `372..375` concrete: lemmas `groupWord (setGroup ..) = ws[j]`, `joinWords` = `wordAt`
  (by construction), and a byte lemma for `splitWords` (8×7 `bv_decide` cases) giving the output bytes.
* `gen_all_rvv.py`: compose 3 segments per aligned batch and 3 segments + 2 concrete copies per
  misaligned batch; `RvvCommon`: a `Mid` with `a7 ≠ 0` and byte-level output/preservation.
Cost: a second, smaller set of segments per `w`; the cores are shared only if the aligned bodies are
restructured at the same time.
